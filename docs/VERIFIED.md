# 확인한 것과 못 한 것 (2026-11-09 기준)

안내 문구는 **눌러 본 순서만** 씁니다. 실제 폰은 아직 시험하지 못했고, 아래는 시뮬레이터·에뮬레이터에서 가짜 명단으로 확인한 것입니다.
실기기 결과는 이슈 양식 **"기기 확인 보고"** 로 알려 주세요.

## 아이폰 — iOS 시뮬레이터

| 항목 | 내용 |
|---|---|
| 환경 | GitHub Actions 맥 러너의 iOS 시뮬레이터: iOS 18.6(영어·한국어), iOS 26.5(영어) |
| 방법 | WebDriverAgent 로 사파리 → 공유 → 연락처 → 저장을 누르고, 시뮬레이터의 연락처 DB(`AddressBook.sqlitedb`)를 sqlite 로 열어 **사람 수·번호를 직접 셈** |
| 결과 | README 의 4단계로 저장됨. 일부만 체크해 만든 파일도 고른 사람만 들어감 |

확인한 화면 글자:

| | 영어 | 한국어 |
|---|---|---|
| 미리보기 왼쪽 위 / 오른쪽 위 | Done / 공유 아이콘 | 완료 / 공유 아이콘 |
| 공유 창 | Copy · Contacts · Save to Files | 복사 · 연락처 · 파일에 저장 |
| 가져오기 화면 | Cancel / Save, 머리글 "Add All N Contacts" | 취소 / 저장, 머리글 "N개의 연락처 모두 추가" |

알아 둘 것:
- 사파리는 `.vcf` 링크를 열면 **첫 사람 한 명짜리 미리보기**만 띄웁니다. `download` 속성은 무시됩니다. 공유 버튼은 그 화면 **오른쪽 위**에 있습니다.
- 공유 창의 "연락처"는 두 군데(위 아이콘 줄, "복사" 아래 목록)에 있습니다. 시험에서는 아래 목록 줄이 두 버전 모두 열렸고, 위 아이콘 줄은 iOS 18 의 좌표 터치로는 열리지 않았습니다(손가락으로는 될 것으로 보지만 확인하지 못했습니다).
- 시뮬레이터에서 연락처 앱이 꺼진 채 "연락처"를 누르면 앱이 안 열리고 사파리 첫 화면으로 돌아오는 일이 있었습니다 → 안내에 "처음부터 한 번 더"를 넣었습니다. 실제 폰에서도 그런지는 모릅니다.

## 안드로이드 — 에뮬레이터

| 항목 | 내용 |
|---|---|
| 환경 | 우분투 러너(KVM)의 안드로이드 에뮬레이터: Android 14(API 34, Google APIs, Pixel 6 프로필), 크롬 + 구글 연락처. 화면 언어는 영어 |
| 방법 | adb·uiautomator 로 크롬에서 페이지를 열고 "5명 저장"을 누른 뒤 화면을 읽으며 누르고, 연락처 제공자(content provider)를 질의해 **연락처 수를 직접 셈** |

확인한 순서와 결과:

1. 크롬에서 "N명 저장"을 누르면 파일(`.vcf`)이 받아지고 화면 위에 **"File downloaded … Open"**(다운로드 완료·열기) 배너가 뜹니다. (페이지의 `download` 속성이 받는 파일 이름이 됩니다.)
2. **"Open"** 을 누르면 구글 연락처가 열리고 **"Save imported contacts to: [Device] [Cancel]"**(가져온 연락처를 저장할 곳) 창이 뜹니다. 에뮬레이터에는 구글 계정이 없어 "기기"만 보였고, 계정이 있는 폰에서는 계정이 같이 나올 것입니다(미확인).
3. "Device"를 누르면 **5명 전원이 저장**됐습니다(연락처 5, 번호 5).
4. 알림을 놓쳐도 **"Files(내 파일) → Downloads"에서 받은 파일을 눌러도** 같은 "저장할 곳" 창이 뜹니다.

**못 한 것:** 삼성 인터넷·갤럭시 연락처(One UI)·기타 제조사 앱, 한국어 안드로이드의 실제 글자, 구글 계정이 로그인된 상태, 실제 폰. 갤럭시 사용자의 보고가 가장 필요합니다.

## 중복 동작 (측정값)

| 환경 / 동작 | 결과 |
|---|---|
| iOS — 오른쪽 위 "저장"으로 **같은 사람을 다시** | 사람이 또 생김(2명을 두 번 → 4명, 5명을 두 번 → 10명) |
| iOS — 머리글 "모두 추가"(Add All)로 **같은 사람을 다시** | 새 사람은 안 생기고 기존에 합쳐지지만 **같은 번호가 한 번 더 붙음**(한 카드에 번호 2개) |
| iOS — Add All, 이름이 같고 번호가 다름 | 기존 연락처에 새 번호가 추가됨 |
| iOS — Add All, 번호만 같고 이름이 다름 | 새 사람으로 만들어짐(번호로는 합치지 않음) |
| Android(구글 연락처) — **같은 파일을 다시** 가져오기 | 연락처 목록에는 5명 그대로(자동으로 한 사람으로 묶임), 내부 원본 기록(raw contact)은 5 → 10 으로 늘어남 |

그래서 페이지는 "이미 저장해 둔 사람은 체크를 끄세요"라고 안내합니다. 웹 페이지는 폰의 연락처를 읽을 수 없어 자동으로 건너뛰게 할 수 없습니다.

## 이 확인의 한계

- 시뮬레이터·에뮬레이터는 실제 폰과 다를 수 있습니다(제조사 앱, OS 설정, 계정 상태).
- 시험은 가짜 이름·번호(`010-0000-xxxx`)로 했고, 실제 명단은 쓰지 않았습니다.
- 확인 도구(맥·안드로이드 러너 스크립트)는 아직 이 저장소에 없습니다. [ROADMAP](../ROADMAP.md)의 "확인 도구를 이 저장소로 옮기기"에 있습니다.
